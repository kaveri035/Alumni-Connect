# 🎓 College Alumni Connect

**Bridging the gap between students and alumni.**

## 📌 About

College Alumni Connect is a web-based platform designed to bring students and alumni together. It provides a space for networking, mentorship, communication, and sharing career opportunities.

## ✨ Features

* Separate Student, Alumni and Admin modules.
* User registration and login.
* Profile management.
* Alumni networking and connections.
* Mentorship requests.
* Messaging and notifications.
* Discussion forums.
* Events and registrations.
* Admin dashboard.

## 🛠️ Tech Stack

* HTML, CSS, JavaScript
* PHP
* MySQL
* XAMPP & phpMyAdmin

## ⚙️ Setup

1. Clone this repository.
2. Move the project folder into XAMPP's `htdocs` directory.
3. Start Apache and MySQL.
4. Create a database in phpMyAdmin.
5. Import the provided SQL file.
6. Configure the database connection.
7. Run the project at `http://localhost/College-Alumni-Connect/`.
